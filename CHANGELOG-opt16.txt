SUNNY opt16 — RainViewer precipitation radar toggle
====================================================

Feature — free precip radar overlay (no keys):
- Toggle checkbox "Radar" next to Labels / International (default OFF).
- Persists in localStorage (sunny-radar) like other toggles.
- MapLibre raster source from RainViewer public weather-maps.json.
- Latest radar.past frame (stability); nowcast only if past empty.
- Tiles: {host}{path}/256/{z}/{x}/{y}/2/1_1.png
  Color 2 = Universal Blue (readable on dark + light basemaps).
  Options 1_1 = smoothed + snow.
- Opacity 0.70 (fixed). maxzoom/native 7; map overzooms beyond.
- Stack: basemap → clouds → radar → Labels → beaches.
- Manifest refresh ~6 min while Radar ON and tab visible; pause when hidden.
- Toggle OFF removes layer+source (no leftover fetches). Fail soft if API down.
- Attribution: RainViewer + existing NASA/Open-Meteo/free tiles.
- Preconnect api.rainviewer.com + tilecache.rainviewer.com.

Cache: ?v=opt16; SW CACHE=sunny-v-opt16
Preserved: opt15 GOES lag/probe, opt14 MODIS day fallback, WX_BATCH
timeouts, Play WMS, SUNNY_CLOUD=20, settings, FPS, PWA, beach layer order.
